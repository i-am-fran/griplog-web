Journal

Every attempt, written down

Write notes on any route as you work it. State changes get logged automatically. Come back a month later and see exactly how the project went.

  • Timestamped entries per route
  • Auto-logged state changes
  • Entries grouped by date
Media

Photos, video & beta drawings

Attach photos and clips to any route. The beta drawing tool lets you mark holds directly on a photo, number the sequence, and tag each one by type and difficulty.

  • Multiple photos & videos per route
  • Drag to reorder media
  • Draw holds directly on photos
  • Share photos from the Photos app

Overview

Know where you stand

Open the app and see your current grade, sends this week and month, active projects, and success rate. A grade pyramid shows how your sends stack up across difficulty levels. Stats load instantly, cached in the background.

  • Current grade per discipline
  • Weekly and monthly send counts
  • Grade distribution histogram
  • Grade pyramid comparing sends vs. goals per grade
  • Recent activity from the last 30 days
  • Active project count and success rate

Events

Trips, comps, gym days

Create an event, attach the routes you climbed and the venues you visited. Route data is snapshotted at log time, so the event stays accurate even if you edit a route later.

  • Multi-day date ranges
  • Multiple locations per event
  • Route snapshots preserved
  • Unsplash cover photos
Sync & Data

iCloud sync

Routes, locations, events, photos. All synced across your devices via CloudKit. Works offline too. You can also export everything as a .griplog file and import it anywhere.

  • iCloud CloudKit, no account needed
  • Offline-first, syncs when back online
  • Export & import as .griplog files
  • Conflict resolution on import
Sharing

Send a route to a friend

Share any route or location as a link via Messages, AirDrop, wherever. When they open it, Griplog pre-fills the form with all the details. Works with Apple Shortcuts too.

  • Route & location share links
  • Pre-filled import form for recipients
  • Apple Shortcuts via x-callback-url
